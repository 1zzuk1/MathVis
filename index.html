    A notebook is a list of statements. Definitions build up an environment; claims are checked by sampling and drawn. LANGUAGE.md has the full grammar.
    
      
    Statements
    
      
    
        
    import topology, sequences
    Load libraries.
    
        
    let M = [[2, 1], [1, 3]]
    Name a value.
    
        
    def f(x) := x^2 - 1
    Define a function. Bodies may use quantifiers, sets and other definitions, including later ones and themselves.
    
        
    def g(x: R^2, s: Seq(R)) := …
    Typed parameters: each argument is checked against its space when the function is called.
    
        
    def D := {p in R^2 | |p| < 1}
    Define a set.
    
        
    theorem name: …
    Check a claim. lemma, claim, conjecture and unnamed check work the same way.
    
        
    plot f(x) for x in [-5, 5]
    Plot numbers against a variable, or points of the plane or of space as a path. With two variables, plot f(x, y) for x in …, y in … draws a surface; an expression giving points (x, y, z) draws a parametric surface.
    
        
    show region(D)
    Open a view that a library provides.
    
        
    explain open
    Show a definition, lemma, function or set: its statement, a plain-English reading, what it uses, and a gallery of examples that do and don’t satisfy it. explain f for x in … picks the examples.
    
        
    check union_of_open
    Check a named lemma or theorem, from a library or from earlier in the notebook.
    
        
    vary continuous_at
    Change one part of a definition (or claim) at a time and show what changes.
    
        
    structure Group(G: Set, op: Fun, e) extends Monoid where inverses: …
    A structure defined by axioms. Group(…) builds one; check g in Group checks each axiom; explain Group tries the examples.
    
        
    concept prime(n: Z) where two_divisors: … wilson: …
    One notion with several equivalent definitions (one per line). Each is a definition of its own (prime_wilson); the card compares them on the examples, disagreements first.
    
        
    interpret x
    Every way of looking at a value: a submanifold as a chart, local equations, a local graph and a straightening; a matrix as a map, by eigenvectors, as a quadratic form; a number as primes or a continued fraction… For interpret prime(7), every form of the concept at 7.
    
        
    {G = Zmod(5), op = add_mod(5)}, g.op
    Records and fields. import topology as top then top.open.
    
        
    proof of name: + indented steps
    let x, assume P, choose δ = …, choose N in D such that P, have P, so P: each step is checked in its context and the goal is tracked. Blocks on indented lines: case x >= 0: … otherwise: …, induction on n with base: and step:, and contradiction (then so false). have P by lemma checks the lemma's hypothesis.
    
        
    diagram name: + indented lines
    Arrows f: A -> B between finite sets or groups, then g ∘ f = h (f first), exact at B or commutes. Checked at every element and drawn; arrows between groups are tested for being homomorphisms.
    
        
    lim n -> inf: s(n)
    Any other line is evaluated and printed.
    
        
    Words… (toolbar)
    Write in English: "for every real number x, x squared is at least 0", "every convergent sequence is bounded", "the sum of k for k from 1 to n equals n(n + 1)/2 for every natural number n". The notation appears, typeset, ready to insert; a sentence only partly understood is marked ?.
    
      
    
      
    Indent a line, or end the previous one with an operator, to continue a statement. # starts a comment; comments right above a def document it.
    

      
    Spaces
    
      
    
        
    R ℝ, Z ℤ, N ℕ
    Numbers. Membership is unbounded; sampling uses [−10, 10], −50..50 and 0..100.
    
        
    [a, b], (a, b], Ioo(a, b), a..b
    Intervals (also Icc, Ico, Ioc) and whole-number ranges.
    
        
    R^2 ℝ², [0, 1]^3, A * B
    Products. Their elements are points such as (1, 2).
    
        
    {p in R^2 | P}, {(x, y) in R^2 | P}
    Sets. Also A ∪ B, A ∩ B, A \ B, complement(A), A ⊆ B.
    
        
    Ball(c, r), ClosedBall(c, r)
    Balls in ℝ or ℝⁿ.
    
        
    Seq(X)
    Sequences in X. Seq(Seq(R)) is sequences of sequences.
    
        
    Set, Fun
    For typed parameters: any set, any function.
    
        
    Disk, Rect, Triangle, Polygon, HalfPlane, Annulus, Ellipse
    Shapes of the plane, as sets; also area, centroid, diameter.
    
        
    Subsets(R^2), Functions(R), Sequences(R)
    Named example objects to quantify over: forall A, B in Subsets(R^2): …
    
      
    

      
    Logic and expressions
    
      
    
        
    forall ∀, exists ∃
    forall x in S, ε > 0, (a, b) in R^2: …
    
        
    and or not -> <->
    Also ∧ ∨ ¬ ⇒ ⇔ and implies, iff.
    
        
    = != < <= > >=
    Chainable. Within 10⁻⁹ (relative) counts as equal: <= includes numbers just over, < excludes numbers just under.
    
        
    sum k in 1..n: k^2
    Also prod, max, min, sup, inf. sup and inf over infinite sets are sampled.
    
        
    lim n -> inf: s(n)
    Limits of sequences; lim x -> a: f(x) for functions. Also lim(s), convergent(s).
    
        
    a + b where a = …, b = …
    Local definitions.
    
        
    |x|  x[1]  x => x^2  if c then a else b
    Length of a number or point, coordinates from 1, functions, conditionals. Points and sequences add and scale coordinatewise.
    
      
    

      
    Finding counterexamples
    
      
      
        
    • Numbers know whether they are rational: sqrt(1/2) is √2/2. Claims about Q, Irrationals, is_rational or the Dirichlet and Thomae functions are sampled with exact fractions and irrationals.
      • 
        
    • import asymptotics: limits, series and continuity of formulas decided exactly (series_test(n => (-1)^n/sqrt(n) + 1/n)), and thresholds of families: show family(p => summable(n => 1/n^p), 0, 3).
      • 
        
    • import models: every small model (groups of order ≤ 8, topologies and posets on ≤ 4 points, relations on ≤ 3 points, operations on ≤ 3 elements), so the first counterexample is a smallest one. import topspaces: infinite spaces by their known properties.
      • 
        
    • import zoo: famous functions and sets (Dirichlet, Thomae, Weierstrass, Cantor, the fat Cantor set, …) that know exact facts about themselves; explain Famous, facts_of(thomae).
      • 
        
    • A failing claim shows its simplest counterexample (simple fractions, earlier catalog objects); a holding comparison gets a targeted search toward failure.
      • 
        
    • Try wilder examples adds pathological functions, sets, sequences, series and matrices to the catalogs.
      • 
        
    • Is every condition needed? drops hypotheses, swaps < and ≤, reorders quantifiers and changes ranges, checking each version, and finds sharp constants.
      • 
        
    • Proved means every case was checked exactly; interval arithmetic proves inequalities on boxes, with a proof map.
      • 
      
    

      
    Working with pictures
    
      
      
        
    • Drag to pan, scroll after clicking (or Ctrl+scroll) or pinch to zoom, double-click to reset. Curves and shaded regions are recomputed for the new view.
      • 
        
    • Sample this view checks a claim again using only the zoomed range; More samples checks it with four times as many.
      • 
        
    • Click a counterexample, a gallery tile or a table cell to see why: the claim evaluated step by step, with the failing case or witness of each quantifier and each definition unfolded.
      • 
      
    

      
    How claims are drawn
    
      
    
        
    Variables after ∀Picture
    
        
          
    noneA verdict, with both sides of a comparison.
    
          
    one numberBoth sides against the variable, failing stretches shaded.
    
          
    two numbers, or a point of a boxA grid colored by result. Darker green means more slack.
    
          
    a point of a setThe set, the sampled points colored by result, and witness balls for “∃ε”.
    
          
    a sequenceA gallery of sampled sequences (paths, in the plane), with their limits.
    
          
    named objects (a catalog)A tile per object, or a table for two variables, colored by result.
    
          
    a point of space (three numbers)A cloud in 3D colored by result; drag to turn it.
    
          
    more numbersRandom samples, left side against right side.
    
            
      
    
      
      
        
    • Sets are sampled inside, near their boundary, and on it: the boundary is found by bisection, which is how open and closed sets are told apart.
      • 
        
    • Seq(X) tries sequences that run into X’s boundary, converge inside X, stay constant, alternate or diverge. They know their own limits.
      • 
        
    • In P -> Q, samples where P is false hold vacuously and are drawn gray.
      • 
        
    • Checking a call to a definition unfolds it, and so are definitions used in its conclusion.
      • 
        
    • Results are evidence, not proof: nested quantifiers use 64, 40 and then 20 samples.
      • 
      
    

      
    Writing libraries
    
      
    The quickest library is a notation library: library name followed by defs, each documented by the comment above it. A JavaScript library calls MathViz.define:
    

    MathViz.define({
  name: 'mylib',
  description: 'One sentence.',
  requires: ['linalg'],
  constants: { golden: 1.618 },
  functions: { sq: { doc: 'sq(x) = x²', fn: x => x * x } },
  spaces: { Annulus: (r, R) => MathViz.space({
              window: [[-R, R], [-R, R]], contains: p => … }) },
  types: [{ name, test, ops: { '+', '*', neg, abs, '=', '<', format } }],
  views: { myview: { doc: '…', render(ctx, ...args) { … } } },
});
    
      
    A space only needs contains plus a sampling window (or a random() function); sampling, boundary search and Seq(…) then work automatically. Views draw with ctx.figure({ x, y, square }) and fig.curve, points, circle, region, raster, add sliders with ctx.param, and report with ctx.legend, ctx.note, ctx.table. README.md lists every helper.
    
    
    
  
    

  
    
    
    
      
    
    
    
    
    
      
      
    Write mathematics, see whether it's true
    
      
    Write definitions and claims in a notation close to the blackboard. Each claim is checked:
        proved when algebra or an exhaustive check settles it, otherwise tested on many examples, and when it's
        false you get the simplest counterexample, drawn. Proofs are checked step by step.
